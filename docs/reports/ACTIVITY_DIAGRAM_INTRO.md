# 3.2 Activity Diagram

An activity diagram models the flow of control within a use case as a sequence of actions and decision points, capturing branching logic, loops, and parallel outcomes that a use case diagram alone cannot show. Following this convention, the activity diagrams for VisionGuard AI first trace the per-frame processing loop as a single end-to-end flow (Level 1), then break it down per module to mirror the use case breakdown in Section 3.1 (Levels 1.1–1.7).
